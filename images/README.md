# Photos

Drop the box photography here with these exact filenames. Until a file
exists, the site shows a labelled placeholder in its place — nothing breaks.

| File               | Used for                                | Suggested size |
|--------------------|-----------------------------------------|----------------|
| `box-hero.jpg`     | Hero shot, top of the page (4:3 crop)   | 1600 × 1200    |
| `box-plantain.jpg` | Plantain Box card + order summary       | 1000 × 1000    |
| `box-fries.jpg`    | Fries Box card + order summary          | 1000 × 1000    |
| `box-bread.jpg`    | Bread Box card + order summary          | 1000 × 1000    |
| `box-simple.jpg`   | Simple Chicken Box card + order summary | 1000 × 1000    |

The card images are cropped square and the summary image to 16:10, so keep the
box centred with a little room around it.
