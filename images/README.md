# Photos

Drop photography here with these exact filenames. Until a file exists the site
shows a labelled placeholder in its place — nothing breaks, and the layout is
already reserving the right aspect ratio, so there is no layout shift when the
real image lands.

## Static hero

| File               | Used for                                        | Suggested size |
|--------------------|-------------------------------------------------|----------------|
| `hero-still.jpg`   | Hero shown to reduced-motion / low-power visitors | 1600 × 1200  |

Make this the single best frame in the whole sequence — for some visitors it is
the only hero they ever see.

## Menu sections (large, landscape)

## Builder cards (square)

| File                 | Used for                                  | Suggested size |
|----------------------|-------------------------------------------|----------------|
| `box-simple.jpg`     | Simple card + order summary               | 1000 × 1000    |
| `box-plantain.jpg`   | Plantain card + order summary             | 1000 × 1000    |
| `box-fries.jpg`      | Fries card + order summary                | 1000 × 1000    |
| `box-bread.jpg`      | Bread card + order summary                | 1000 × 1000    |

Cards crop square, the order summary crops to 16:10, so keep the box centred
with a little room around it.
